# Pulsar Kids (POC)

Сенсорний, доброзичливий веб-простір для навчання дітей 3–10 років.
Це **proof-of-concept** фронтенду: мобільний Хаб із каталогом, повноцінний
модуль **Математика**, двигун тем, артефакти, скарбничка та кабінет батьків.
Zero-backend — усе працює в браузері (LocalStorage).

## Запуск

Найзручніше — через скрипт із кореня репозиторію (порт 4321, не 5173, і з
доступом по локальній мережі для телефона/планшета):

```bash
./scripts/dev.sh          # гра: http://localhost:4321 (+ Network URL для мобільного)
./scripts/dev.sh 4500     # власний порт
./scripts/dev.sh site     # сайт: http://localhost:4322
./scripts/dev.sh all      # обидва
```

Або напряму:

```bash
cd app
npm install
npm run dev:game   # гра: http://localhost:4321 (host увімкнено)
npm run dev:site   # сайт: http://localhost:4322
npm run build      # продакшн-збірка обох (game/dist, site/dist)
npm test           # тести всіх частин
```

## Структура репозиторію

Сайт і гра — два окремі проєкти (npm workspaces), кожен деплоїться сам
(`./scripts/deploy.sh` питає, що пушити):

```
site/        публічний сайт (pulsarkids.com): свої стилі, скрипти, тексти й переклади
game/        гра: панель дитини, кабінет батьків, адмін-панель та API (play.* / parents.*)
packages/    лише те, чим користуються обоє
  i18n/      рушій перекладів (без текстів і без переліку мов)
  platform/  про що сайт і гра домовились: хости, cookie мови, джерело відвідувача
  brand/     іконки й кольори нічного неба
```

Подробиці — у `CLAUDE.md` та `docs/architecture.md`. Решта цього файла описує
ранній POC гри; шляхи `src/…` нижче — усередині `game/`.

### Перевірка на мобільному
Запусти `./scripts/dev.sh`, відкрий на телефоні/планшеті (та сама Wi-Fi) адресу
`Network`, яку надрукує Vite (напр. `http://192.168.1.228:4321`). Проєкт
mobile-first: великі зони дотику (≥56px), без зуму по подвійному тапу,
безпечні зони під «чубчик», адаптивні завдання та підказки.

## Що вже працює (Фаза 1 MVP з PRD)

- **Хаб-вітрина**: фільтри за віком / предметом / складністю, анімовані картки.
- **Математика** (`Математичний Маг`): Усний рахунок, Магія множення, Смачні дроби.
- **Zero-Aggression**: немає програшу/таймерів. Після 2 помилок з'являється
  сенсорна підказка (вежі-десятки з пентатонічними дзвіночками, збільшена тарілка).
- **Двигун тем «100500»**: 6 тем (Єдинороги, Тачки, Космос, Динозаври, Підводний
  світ, Ліс) — міняють кольори, маскота, артефакт, святкування й «Корабель мрії».
- **Супутник-перегони**: маскот їде до своєї цілі в міру виконання завдань.
- **Святкування**: конфеті + тематичні емодзі + синтезований звук (5 стилів).
- **Звук і голос**: Web Audio синтезатор (дзвіночки, «ПОП!», «хрум», фанфари) та
  озвучення умов українською (Web Speech API).
- **Скарбничка**: лічильник артефактів, «Сімейна мета» (Parent Goal Contract),
  соло-будівництво «Корабля/Замку/Ракети».
- **Кабінет батьків**: вхід через приклад множення; налаштування сесії, швидкості
  супутника, стилю святкування, звуку, цілі та скидання прогресу.

## Архітектура (Micro-Kernel Plugin)

```
src/
  core/            # ядро, нічого не знає про конкретні предмети
    kernel/        # контракт LearningModule + реєстр плагінів
    theme/         # двигун тем (CSS-змінні)
    audio/         # Web Audio синтезатор + Web Speech TTS (+ hooks)
    store/         # Zustand, збереження у LocalStorage
    utils/
  modules/
    math/          # плагін «Математика» — реєструє себе в ядрі
  components/      # UI: ui/ hub/ game/ reward/ parent/ layout/
  pages/           # Hub / Game / Vault / Parent
```

### Як додати новий предмет (напр. Географію)

1. Створити `src/games/geography/` із генераторами завдань і React-компонентом
   гри, що реалізує контракт `LearningModule`.
2. Додати один рядок `import './geography';` у `src/games/index.ts`.

Ядро та Хаб **не змінюються** — каталог підхопить новий модуль автоматично
(`CoreApp.registerModule` з PRD §9).

> Примітка: контракт `renderGameView(container: HTMLElement, …)` з PRD адаптовано
> під React — модуль надає компонент `GameView` замість імперативного рендера.
